# Hosting Capacity de uma Barra

Animação educacional em Manim Community Edition para explicar a hosting capacity de uma barra de um sistema elétrico de potência com geração distribuída fotovoltaica.

## Cena

A classe principal é `HostingCapacityBus`, implementada em `hosting_capacity_bus.py`.

## Renderização

Renderização em alta qualidade:

```powershell
manim -pqh hosting_capacity_bus.py HostingCapacityBus
```

Renderização em baixa resolução:

```powershell
manim -r 426,240 --fps 15 hosting_capacity_bus.py HostingCapacityBus
```
